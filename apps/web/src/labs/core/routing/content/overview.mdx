# Routing

Routing is the boundary between a URL and application state. This lab uses TanStack Router's
generated file routes, validated search parameters, typed links, and a pathless authentication
layout.

## What the lab demonstrates

- File names as the route-tree source of truth
- Typed links and navigation targets
- URL-backed state through validated search parameters
- Authentication guards for page navigation
- Separate API authorization for data security

## Request flow

```text
URL → generated route match → search validation → auth layout → component
```
