# Forms

Forms turn browser input into an intentional submission. This lab keeps fields controlled while
retaining native form semantics, labels, keyboard submission, and a visible result.

## What the lab demonstrates

- Controlled React fields with one draft object
- Native submit behavior through a real `<form>`
- Stable names, labels, limits, and required constraints
- A submitted snapshot separate from the editable draft
- Feedback exposed through a status region

## Request flow

```text
Input event → controlled draft → form submit → submitted snapshot → status
```
