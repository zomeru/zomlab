# CRUD Notes

CRUD covers the core operations for creating, reading, updating, and deleting data.
This lab implements those operations as an authenticated notes feature from the UI to
PostgreSQL.

## What the lab demonstrates

- Shared Zod contracts for API inputs and responses
- Protected Hono routes for each CRUD operation
- User-scoped data access that keeps notes private
- A service and repository boundary around Drizzle
- Typed TanStack Query hooks for server state

## Request flow

```text
Notes UI → TanStack Query → Hono → NoteService → NoteRepository → Drizzle
```

Every operation carries the authenticated user's ID through the stack. Missing notes
and notes owned by someone else both return `404`, so the API does not reveal whether
another user's note exists.
