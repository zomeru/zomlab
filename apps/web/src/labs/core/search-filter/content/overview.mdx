# Search and Filtering

Search and filtering turns a growing collection into something people can navigate quickly.
This lab extends the authenticated notes API with a case-insensitive query across note titles
and content.

## What the lab demonstrates

- A validated `query` parameter shared by the API and client
- User-scoped filtering in the Drizzle repository
- URL-backed search state with TanStack Router
- Query-specific TanStack Query cache keys
- Accessible result counts, clear controls, and empty states

## Request flow

```text
Search field → URL query → TanStack Query → Hono → NoteService → Drizzle ILIKE
```

The repository always combines the search expression with the authenticated author's ID, so a
search can never return another user's notes.
