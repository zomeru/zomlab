## Ownership check on update

<Mermaid
  chart={`
sequenceDiagram
  participant Browser
  participant Elysia
  participant Service
  participant DB

  Browser->>Elysia: PATCH /api/notes/:id
  Elysia->>Service: update(user.id, id, payload)
  Service->>DB: repository.findById(id)
  DB-->>Service: Note (or null)
  alt note missing OR authorId != user.id
    Service-->>Elysia: throw NoteNotFoundError
    Elysia-->>Browser: 404 Note not found
  else owned
    Service->>DB: repository.update(id, payload)
    DB-->>Service: Note
    Service-->>Elysia: Note
    Elysia-->>Browser: 200 Note
  end
`}
/>

## Why 404 and not 403

Returning `404` for another user's note hides whether the resource exists at all.
`403` would leak that a note exists but is forbidden; `404` keeps the API surface
uninformative to outsiders.
